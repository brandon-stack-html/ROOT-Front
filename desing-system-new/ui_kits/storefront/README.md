# UI kit — Storefront

Recreación de la **tienda pública** del restaurante demo "El Buen Sabor":
header con marca + nav (Inicio · Carta · Sucursales · Nosotros · Contacto) +
carrito, **hero** con gradiente de marca ("El sabor de Colombia en tu puerta",
CTA "Pedir ahora", chips de envío/tiempo/rating), **carta** filtrable por
categoría con grid de productos en COP, y **barra de carrito flotante** que
aparece al agregar.

Archivos: `index.html`, `app.jsx`, `kit.css`. Interactivo: filtros de categoría
y agregar al carrito (actualiza contador, total y la barra inferior).

> Las fotos de producto son placeholders tintados con ícono (no hay fotografía
> real disponible). Reemplázalas por imágenes reales en producción.
