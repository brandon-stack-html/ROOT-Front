# UI kit — App Mesero

Recreación de la app móvil del mesero de ROOT en **frame iPhone** con
**bottom-tab** (Mesas / Comandas / Nómina / Mi perfil). Incluye dos pantallas
completas:

- **Mapa de mesas** — grid por zona (Salón Principal, Terraza) con estados
  translúcidos (libre / ocupada / por cobrar / reservada), comensales y total.
- **Mi nómina** — hero con countdown "Próximo pago", barra de progreso del
  periodo, desglose (salario base, devengado, adelantos, disponible) y CTAs
  táctiles "Solicitar adelanto" / "Ver mis adelantos".

Archivos: `index.html`, `app.jsx`, `kit.css`. Mesero demo: **Camila Rojas**
(emp-001, Sede Norte, quincenal, $1.623.500). Toca el bottom-tab para cambiar
de pantalla.
